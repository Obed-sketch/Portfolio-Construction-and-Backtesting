# Portfolio-Construction-and-Backtesting

Quantitative finance coursework notebooks (University of Iowa):

- `Demo Portfolio Construction and Backtesting (1).ipynb` — portfolio
  construction and backtesting.
- `Demo Quantitative Stock Selection Model_ Analyst Forecast Dispersion (1).ipynb`
  — stock-selection model based on analyst forecast dispersion (IBES data).
- `Demo Quantitative Stock Selection Model_ Asset Growth (2).ipynb` —
  stock-selection model based on asset growth.

All three notebooks are fully executed, with outputs saved in the files.

## Data — synthetic stand-ins (new Nov 2026)

The notebooks read CSV files from a `classdata/` folder. The originals
are licensed Compustat/CRSP/IBES course extracts and are not
redistributable. The copies now bundled in `classdata/` are **synthetic
stand-in data** generated by `make_synthetic_classdata.py`, with the
exact schemas the notebooks expect (300 firms; PERMNO 93433, 32548 —
whose zero-asset years produce the `inf` signal the Asset Growth
notebook discusses — and 10421, whose 2001 fiscal-year-end change
produces the duplicate Date=200206 signal; CUSIP 87482X10 with Q4-2014
observations). `classdata/Signal1.csv` and `classdata/Signal2.csv` are
the outputs the Asset Growth and Forecast Dispersion notebooks
themselves write, kept in `classdata/` because the Portfolio
Construction notebook reads them from there. A mild asset-growth
effect is deliberately baked into the synthetic returns.

**All results in the executed notebooks are computed on this synthetic
data and are illustrative only — they are not real market results.**

## Run status (verified Nov 2026)

All three notebooks were re-executed top-to-bottom against the bundled
synthetic data with **zero errors**; the saved outputs are from those
runs. Headline output of the Portfolio Construction backtest on the
synthetic data: asset-growth signal — mean quarterly excess return
0.0249, t = 6.12, information ratio 0.69; forecast-dispersion signal —
mean -0.0032, t = -0.76 (no effect was baked in for that one). To
reproduce, in order:

```bash
pip install -r requirements.txt
python make_synthetic_classdata.py   # regenerates the classdata inputs
jupyter nbconvert --to notebook --execute --inplace \
    "Demo Quantitative Stock Selection Model_ Asset Growth (2).ipynb"
jupyter nbconvert --to notebook --execute --inplace \
    "Demo Quantitative Stock Selection Model_ Analyst Forecast Dispersion (1).ipynb"
mv Signal1.csv Signal2.csv classdata/   # the two notebooks write these
jupyter nbconvert --to notebook --execute --inplace \
    "Demo Portfolio Construction and Backtesting (1).ipynb"
```
